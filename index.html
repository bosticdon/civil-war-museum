HTML5 Deployment & Archiving Guide

How to Save, Customize & Host Your HTML5 Museum

1. Save This Single-File HTML5 App Locally

Save this code as index.html on your computer. Because it uses standard HTML5 (<!DOCTYPE html>, <dialog>, <canvas>, and WebGL), you can double-click index.html to open it directly in Chrome, Edge, Safari, or Firefox with zero server setup.

2. Load Your PowerPoint Photos (Saved Automatically)

In PowerPoint (MK History Project .pptx), right-click each photograph and choose Save as Picture... (JPG or PNG). Inside this virtual museum, open any exhibit placard and click Replace Exhibit Photo (or drag and drop the image onto the viewer). Your photos are automatically saved in your browser's localStorage so they persist across visits.

3. Publish Free Online (GitHub Pages or Netlify)

  • Netlify Drop: Visit app.netlify.com/drop and drag your folder containing index.html onto the page to get a shareable link in seconds.
  • GitHub Pages: Create a new repository, upload index.html, and enable Settings → Pages → Deploy from branch (main).
